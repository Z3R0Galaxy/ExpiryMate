# Requirements
## In Scope
### Must Have Items
- The system must allows users to input and track the expiry dates of food items.

- The user interface must allows users to easily add items, edit the name and expiry date of items, and remove items after they have been used. 

- The system must allow users to input the quantity of items they have
    
- The system must Notify users when a specific item is about to reach its expiry date
    
- There must be a database that stores the name and expiry date of each food item and user information such as email and password 

### Nice to have Items   
- The system must generate recipe suggestions based on ingredients that are close to expiring using an integrated ai. 

- The system must support multi-user household sharing, with shared pantry and household collaboration features.

## Out of scope
- Barcode/QR code scanning — items must be added manually ie no automatic product lookup from barcodes
- Nutritional information — no tracking of calories, macros, or dietary data for items
- Image recognition — items cannot be identified or added via photos.
