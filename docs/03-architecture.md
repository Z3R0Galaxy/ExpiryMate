# Data Dictionary

## Items Table

| Variable | Data Type | Format for Display | Size (Bytes) | Size for Display | Description | Example | Validation |
|---|---|---|---|---|---|---|---|
| id | UUID | — | 16 | 36 chars | Unique identifier for each item, auto-generated | 3f2a1c… | Must be unique; generated by the database |
| user_id | UUID | — | 16 | 36 chars | Foreign key linking the item to its owner; references the Users table | 9b4e2d… | Must match an existing user id |
| name | String | XX…XX | Up to 255 | Up to 255 chars | Name of the food item | Milk | Required; any non-empty string |
| expiry_date | Date | DD/MM/YYYY | 4 | 10 chars | The date the item expires | 23/08/2026 | Required; must be a valid calendar date |
| quantity | Integer | NN | 4 | Up to 3 chars | Number of units of the item the user has | 3 | Required; integer between 1 and 999 |
| created_at | Timestamp | DD/MM/YYYY HH:MM | 8 | 16 chars | Date and time the record was created | 07/05/2026 09:00 | Auto-generated by the database |

## Users Table

| Variable | Data Type | Format for Display | Size (Bytes) | Size for Display | Description | Example | Validation |
|---|---|---|---|---|---|---|---|
| id | UUID | — | 16 | 36 chars | Unique identifier for each user, auto-generated | 9b4e2d… | Must be unique; generated by the database |
| email | String | XXX@XXX.XX | Up to 255 | Up to 255 chars | Email address used to log in | user@example.com | Required; must be a valid email format |
| password | String (hashed) | — | 60 | Not displayed | User's password, stored as a secure hash — never in plain text | — | Required; minimum 6 characters |
